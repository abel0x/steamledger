# Changelog

All notable changes to this project are documented here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and the project uses
[Semantic Versioning](https://semver.org/).

## [1.0.0] - 2026-11-07

### Added

- `setup`, `collect`, `build`, `list`, `show`, `diff`, `open`, `serve`, `prune`,
  `schedule`, `config`, `doctor` and `demo` commands, plus an interactive menu.
- Dated snapshots of the profile, library and playtime, achievements with global
  rarity, friends, badges, groups, wishlist and store details.
- An offline database: JSON, CSV and an HTML report per snapshot, with images
  stored locally.
- A static site with overview, games, achievements, friends, profile, history
  and compare pages, a snapshot timeline, and light and dark themes.
- Comparison of any two snapshots in the terminal, the reports and the site.
- Daily or weekly collection through Task Scheduler, systemd or cron.
- English and Turkish throughout.
